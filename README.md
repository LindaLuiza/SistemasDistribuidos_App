Desenvolvido por Linda Medeiros e Manuela Rattes
Disciplina de Sistemas Distribuidos
UFCI/RJ - Petrópolis
Novembro de 2026

## Objetivo

Este aplicativo tem como objetivo mostrar dados sobre a participação de mulheres na política.

## Login

O usuário deverá fazer login ao entrar no aplicativo de uma das seguintes maneiras:

- Login e Senha
Usuário cria um login fornecendo um login e senha

- Gmail
Usuário loga direto com sua conta do Google

O login é registrado em uma aplicação do Firebase do Google.

O usuário tem a opção de deslogar uma vez que fizer o loggin
